# PlacementPrep Tracker

A responsive placement preparation workspace built with HTML, CSS and vanilla JavaScript.

## Features
- Track applications by company, role, status, date and notes.
- View application, interview and offer counts.
- Search applications and filter by status.
- Follow a preparation checklist for Java, SQL, DBMS, OS, CN, DSA, aptitude and interviews.
- Draft answers to common interview questions.
- Export application and preparation data as JSON.
- Save data locally in the browser with localStorage. No backend or external dependencies.

## Run locally
Clone or download this repository and open `index.html` in a modern browser.

## Deploy with GitHub Pages
The included GitHub Actions workflow deploys the site on pushes to `main`.
1. Open **Settings → Pages** in this repository.
2. Select **GitHub Actions** as the build and deployment source if needed.
3. Check the **Actions** tab for the deployment result.
4. Expected URL: https://shashanknagabhushana.github.io/placement-prep-tracker/

## Privacy
Your entries remain in the browser's local storage and are not synced between devices. Export a JSON backup periodically.
